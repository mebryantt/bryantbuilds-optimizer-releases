Smoother games, measured. A Windows tool from **Bryant Builds** that scans your PC, fixes the gaming settings that actually matter, and proves the result with before/after benchmarks.

## What it does

- **Ready to play:** a 10-second check before you game. It puts back settings Windows undid, cleans temp files, and lists anything worth closing.
- **Scan:** RAM speed (XMP/EXPO), Resizable BAR, GPU driver, monitor refresh rate, overlays, background apps and drive health, with each finding explained in plain English.
- **Tweaks:** only settings with a real, measurable effect. Every change is snapshotted first and can be undone with one click.
- **Benchmark:** average FPS, 1% lows and stutter, before vs. after, plus what's limiting your PC (CPU, GPU, VRAM or heat).
- **Game presets:** the exact settings for popular competitive games, matched to your hardware.
- **Startup apps, network check, tray mode and game auto-detect.**

It never injects into games or edits game files, so it's safe with Vanguard, Easy Anti-Cheat and BattlEye.

## First launch

Windows may show **"Windows protected your PC"** because this is a new app. Click **More info → Run anyway**. The app then asks for administrator access, which it needs to change Windows settings.

## Updates

The app checks for updates on its own once a day. You can also check any time from **Settings → Check for updates**.

## Need hands-on help?

Some problems need hands-on work: BIOS settings, cooling, or failing parts. **Bryant Builds** can diagnose and fix them for you.
